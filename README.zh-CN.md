# AURA MCP

**FHE 是基础计算层，MCP 让 AI 智能体能够连接密文计算服务。**

[English](README.md) · [演示流程](docs/INVESTOR-DEMO.md)

## 请先了解

**本项目演示什么。** 通过 MCP 连接 Aura 协处理器，在密文上执行数值运算，
并导出加密结果。数值计算本身就是 FHE 的应用场景，更复杂的应用由这些基础
运算组合而成。公开演示使用固定的公开样例数值，便于重复测试。
本地只需安装 Node.js 和 MCP，计算引擎运行在远端。

**生产部署如何工作。** 要实现对计算服务方的数据保密，需要由数据拥有者在
自己的环境中生成密钥并加密，服务端执行密文计算，授权接收方在本地解密。
当前版本提供公开演示和运维人员配置的密文输入接入方式，尚未交付经过验证的
本地密钥工作流。公开演示的密钥、加密和解密由演示后端管理。

**目前开源什么。** 本仓库公开 MCP 连接层、连接层测试和合成数据验证脚本。
客户端密码实现、协处理器实现和密码学证明套件不在本仓库中。
后续开源范围与时间由 Aura 另行公布。

## 安装和连接

需要 Node.js 20+，无需 Git 或 npm 账号。

```sh
npm install -g @aurafhe/mcp@preview
aura-fhe-mcp --config cursor --demo
```

将 `cursor` 替换为 `claude` 或 `vscode`，将生成的 Aura 配置加入客户端设置，
保留原有服务器配置，然后重新连接。固定版本为 `@aurafhe/mcp@0.5.0-rc.5`。
[各客户端设置位置](docs/QUICKSTART.md)。

向智能体提问：

> 运行 aura_start，说明当前模式和可用运算。获取固定演示输入，将整数输入
> 0 和 1 相加，再导出加密结果。

## 当前能力与应用路径

- 整数和浮点数的加、减、乘、除。
- 组合求和、乘积、浮点均值和使用加密权重的加权和。
- 请求耗时和密文字节数；耗时包含网络和服务检查，不等于纯引擎耗时。
- 独立合成数据验证脚本报告预期值、实际值、绝对误差和容差。
- 二进制运算计划在下一个版本提供。
- 数据库、模型推理和定制业务逻辑属于独立应用集成。
  如需了解应用演示或技术尽调，请联系 **gen@afhe.io**。

## 模式和验证边界

| 模式 | 当前状态 | 验证边界 |
| --- | --- | --- |
| 固定公开演示 | `--demo` 可用 | 演示功能，不证明服务方无法解密 |
| 运维密文输入 | 需配置输入文件、认证和匹配工作节点 | 节点声明不等于密钥隔离证明 |
| Verified 客户端/服务端模式 | 当前版本未交付 | 需要本地密码客户端、服务端验证和安全审查 |

`aura_start` 介绍工作流并检查连接，不会把未执行的算术或安全测试标成通过。
`aura_roadmap` 区分现有能力、应用路径与计划；`aura_proof` 返回证据状态，
不是密码学证明或安全认证。成功结果和已处理的运算错误均标记模式，
`confidentialityClaimed` 均为 `false`。框架提前拒绝的协议参数错误除外。

MCP 不接收用户明文、私钥或任意文件路径。结果在 MCP 内保持加密，验证和
授权解密在外部进行。公开演示请使用合成数据；机密生产部署需要经验证的
密钥隔离和访问控制。[部署安全说明](docs/SECURITY-MODEL.md)。
